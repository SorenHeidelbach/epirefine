pbinner · methylation-based plasmid–host assignment

Summary

Plasmid assignments

Each plasmid candidate gets a posterior over the host bins plus an "unknown host" class. The filters below apply to the table and both matrices in this section.

Methylation fingerprints

Fraction of motif sites methylated (φ). Each host bin's row is followed by the plasmids assigned to it, with observed φ. ● marks a motif the plasmid methylates with its own MTase; ✕ marks a motif its host fails to explain.

Show as table

Posterior over hosts

Posterior probability of each candidate host per plasmid. Rows follow the assignment order of the table above.

Calibration on pseudo-plasmids

Fragments cut from host contigs, scored leave-one-out against their own bin. Test A keeps the source bin as a candidate; test B removes it, so the right answer is "unknown". These describe the whole run and are not affected by the filters above.

Reliability

Accuracy within bins of stated confidence. Points on the diagonal are calibrated; below it is overconfident.

Performance by fragment length

Test A accuracy and 95% credible-set coverage, and test B rate of calling "unknown" when no lookalike bin exists.

Assignability predicts accuracy

Fragments grouped by the expected log Bayes factor over the nearest competing bin, computed from site positions and coverage only.

Between-chunk variation τ

Leave-one-out log-likelihood of the fragments for each τ, relative to the best. ∞ means chunks share the host level exactly.

Model diagnostics

Caller behaviour per motif group

Learned mean fraction of reads called modified at unmethylated sites (false-positive level μ0) and at methylated sites (detection ceiling μ1).

Show as table

Plasmid parameters δ and τp

Marginal log-likelihood of all plasmid candidates, relative to the best cell (outlined). δ scales the host methylation level; τp sets how much plasmids vary around it.

Bin contamination check

Probability that each 50 kb host chunk is foreign to its bin. Gaps separate contigs. Chunks above 0.5 are excluded from host profiles and calibration.
